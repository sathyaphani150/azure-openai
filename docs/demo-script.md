# Demo Script

1. Show `/ready` and the seven indexed PDFs.
2. Ask: “My VPN says authentication failed after I changed my password. What should I do?” Show PDF/page evidence.
3. Ask an unsupported HR or travel-policy question and show safe escalation.
4. Upload a sanitized IT error screenshot.
5. Generate a guide for “Teams calls have no audio.”
6. Classify “Outlook will not sync my mailbox” and compare zero-shot with few-shot.
7. Run the role demonstration and show all role messages.
8. Show token usage and request IDs, then explain quota/error handling.

Use follow-up questions to demonstrate retrieval diversity: VPN connected but internal resources fail, Wi-Fi connected without internet, recurring account lockout, laptop battery swelling, installer error 1603, Outlook web-versus-desktop isolation, and policy escalation boundaries.

Never use inputs containing real credentials, tokens, personal data, or confidential information.
